# XXD Panel 018｜极简层叠剪纸微排版生产提示词

## 运行时完整画布契约（最高优先级）

- `TOP_BOTTOM` 与 `LEFT_RIGHT` 默认把当前原图作为高保真编辑／参考输入，用本提示词一次生成一张完整成品；不要预先拆成摄影半幅和设计半幅。
- 上下模式在整张成品中保留上方约 50% 的高保真原图，在下方完成本风格转译；左右模式对应左侧约 50% 原图与右侧风格转译。两区要在色彩、光线、节奏、文字与含义上形成一体化设计。
- `DESIGN_ONLY` 与 `WALLPAPER_PACK` 使用完整画布，原图只作身份与内容依据而不显示。壁纸仍按设备分别重新构图。
- `FINAL CANVAS` 指整张最终成品比例／像素，必须由用户在生成前明确；不得静默采用源图尺寸。`DESIGN FRAME` 只在完整画布重试失败并触发确定性拼合兜底时使用。
- 完整画布失败时只针对失败条件重试一次；仍失败、用户要求原片逐像素不变、当前通道无法实现目标画幅，或需要无创像素校准时，才允许脚本拼合。

### 模型优先级与凭据

- **优先使用 GPT Image 2。** 当 GPT Image 2 通过当前内置图像工具或已配置兼容通道可用时，先用它完成本提示词要求的高保真垫图／编辑与完整画布生成。
- 也支持 Seedance 5.0 Pro、Nano Banana Pro（Gemini Image Pro）、Nano Banana 2（Gemini Image Flash）或其他兼容位图模型，但只有实际通道具备原图保真、整张成品画幅、目标语言文字，以及连贯壁纸所需多图参考能力时才可使用。
- 备用模型只替换生图通道，不得改变本提示词的模式、画幅、原图可见性、文案、语言、壁纸关系或“完整画布优先、拼合仅兜底”的执行逻辑。不能满足硬性条件时不得静默降级。
- 没有合适通道时，请用户启用生图工具或提供 API Key。用户主动提供凭据可以用于当前任务，但不得在回复、日志或提示词中回显、展示、记录或泄露其值；未经明确要求不得长期保存或修改全局路由配置。
- 按实际生图能力判断可用性，不因某个工具、供应商名称或单一环境变量缺失就武断判定全部通道不可用。

只处理当前任务明确提供的一张源照片。先锁定主体或不可拆分关系、轮廓、姿态、动作、结构、尺度、负形、方向与距离，至少保留三个源图专属识别线索。不要借用旧成品、样张或其他输入的主体、纸层、配色、文字和构图。

## 一个视觉锚点与少量纸层

选择一个核心主体或不可拆分关系作为唯一视觉锚点。保留原图的关键轮廓、比例、姿态、动作和关系，通过折叠、切割、层叠和遮挡概括，不机械复刻细节，也不把主体复制成多个纸艺对象。

人物保留姿态、朝向、衣着体块与关系距离；动物保留身体节奏和头部方向；植物保留生长走势；建筑保留天际线和关键开口；器物与交通工具保留功能轮廓和负形；景观保留源图专属地平线、地形或空间关系。

只从原图选择少量真正必要的环境关系，分别转化为前景、中景和背景纸层。每一层必须承担深度、尺度、方向、遮挡或叙事关系；禁止用纸片填空、重复主体、碎片漫天、复杂堆积、过量折面、装饰嵌套和第二视觉中心。

## 清楚的层级与大面积留白

通过尺度差、几何轴线、正负形、前后遮挡和大面积暖象牙或浅色留白组织画面。视觉锚点可以偏心、轻微裁切、延展或悬置，但必须保留主要身份线索与动作方向。

折痕只出现在源图有依据的关节、平面转折、方向或深度关系处。切边清晰并显示纸张厚度，每层只向紧邻后层投下柔和接触影。阴影解释层叠，不把画面塑造成独立的多切面雕塑。

不同设备和画幅必须重新组织视觉锚点、前中后层、负空间、标题和微型文字路径；不得机械居中、裁切或缩放另一张成果。

## 源图色彩角色与哑光纸感

从源图提取最具辨识度与生命力的颜色，分配为一个主色、一个深色结构色、一个浅色层次色，以及至多一个极小的源图支持强调色。色彩角色用于身份、层间分离、轴线与重点，不固定色卡，也不无控制地使用彩虹色。

以暖象牙或与原图协调的浅色纸面为基底。使用细腻哑光卡纸、可见纸纤维、清晰切边、真实厚度与柔和接触影；自然漫射光只用于说明纸层关系。

禁止塑料、金属、黏土、泡沫板、廉价卡纸、亮膜高光、假倒角、霓虹色、复杂渐变、硬商品光、低多边形渲染和 3D 默认材质。

## 完整高级编辑微排版

服从已锁定的自动文案、用户准确文案或无文字模式，以及目标语言／地区。用户准确文案逐字保留；无文字时不生成任何字母、字符、数字、纸艺文字或伪文字。

自动文案从主体身份、已知地点、动作、材质、情绪、关系或有依据的象征意义中提炼一个简短主标题，并搭配 2–4 组极小辅助文字，可选对象名称、用户提供或可靠确认的地点、构图编号、章节标记、序列号、坐标式构图数字、方向词、状态词、材质词、分类标签或一句极短诗意注释。

自动文案不得发明或使用年份。地点、日期、出处、坐标和事实数字必须由用户提供或可靠确认。用户准确文案即使包含年份也逐字保留；无年份规则只约束自动创作。

主标题负责识别与情绪，小字负责秩序、节奏、分类与精致感。主标题可适度转化为剪纸或折纸字形；2–4 组小字保持纤细、克制、准确，并通过明显字号反差和方向变化形成阅读路径。

文字可沿纸层边缘、主体轮廓、几何轴线或负空间排列；可按文字系统自然能力使用横排、竖排、旋转、宽字距、贴边、压角、跨色块、嵌入纸层或部分遮挡。不同文字系统保持自然字形、连接、方向、空格与语义换行，不把拉丁方块折字和字距强套给中文、日文、韩文或阿拉伯文。

## 模式与验收


硬性验收：一个视觉锚点保留至少三个源图线索与主要动作或关系；只有少量有依据的前景、中景、背景纸层；折叠、切割、层叠、遮挡、尺度、轴线和正负形清楚且物理可信；大面积暖象牙或浅色留白；主色＋深结构色＋浅层次色＋至多极小强调色；哑光纸纤维、清晰切边、真实厚度与柔和接触影；一个短标题＋2–4 组准确微文字建立阅读路径；自动文案无年份，用户准确文案逐字保留；无主导多切面雕塑、重复主体、装饰碎片、复杂堆积、卡通折纸、儿童手工、塑料 3D、电商展示、廉价卡纸、照片残片或伪文字。

若任一硬性条件失败，纠正生成资产，不要用程序绘图、SVG、HTML、Canvas 或后期文字覆盖伪造成品。
